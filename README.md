# Tarjimly

A Windows desktop screen-translation utility. It uses local Tesseract OCR to extract text from a selected screen region, then translates the extracted text.

## Run
On Windows, run `Install-And-Run.bat` and follow the setup prompts.

## Shortcuts
- `Ctrl+Alt+T`: select a screen region and translate its text.
- `Ctrl+Alt+S`: select existing text with the mouse and translate it.

See the installer and Python source files for implementation details.
